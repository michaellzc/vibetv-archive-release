# Vibe Media Downloader

A Mac app that sends magnet links to Real-Debrid and downloads the files into your media folders,
named for Jellyfin and Plex.

This repository only hosts releases. Download the latest version from
[Releases](https://github.com/michaellzc/vibe-media-downloader-release/releases/latest): open
`Vibe-Media-Downloader-<version>.dmg` and drag **Vibe Media Downloader** into **Applications**.

- Requires macOS 14 or later and a Real-Debrid premium account.
- Signed with a Developer ID and notarized by Apple.
- Updates itself: it checks this repository's latest release once a day and installs new versions.
